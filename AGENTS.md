# Project instructions

Build the AI interviewer described in PROJECT_SPEC.md.

Priorities:

1. Build a complete text-only sample-mode flow first.
2. Keep the app runnable after every phase.
3. Use TypeScript strict mode.
4. Never expose or commit API keys.
5. Store real secrets only in .env.local.
6. Add tests for interview state, schemas, and sample mode.
7. Run lint, tests, type checking, and production build before declaring work complete.
8. Do not begin voice features until the text-only flow works end to end.
